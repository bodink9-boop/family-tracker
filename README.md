# Family Tracker

MVP สำหรับติดตามพิกัดคนในครอบครัวแบบเรียลไทม์

## สิ่งที่ทำได้ตอนนี้

- ดูตำแหน่งสมาชิกหลายคนบนแผนที่เดียวกัน
- ให้สมาชิกแต่ละคนเปิดลิงก์จากมือถือแล้วกดแชร์พิกัดได้
- แสดงเวลาอัปเดตล่าสุด, ความแม่นยำ, และระดับแบตเตอรี่
- เปิดและปิดสัญญาณ SOS ได้
- คัดลอกลิงก์ห้องเพื่อส่งให้คนในครอบครัวได้
- ติดตั้งเป็นแอปบนมือถือแบบ PWA ได้
- ตั้งรหัสผ่านก่อนเข้าแอป และออกจากระบบได้
- หัวหน้าครอบครัวสร้าง QR Code เพื่อชวนสมาชิกเข้าห้องได้
- มีโครง Android app สำหรับต่อไปยัง Play Store แล้ว

## วิธีเปิดใช้งาน

1. ติดตั้ง dependencies แล้ว
2. รันแอปด้วยคำสั่ง `npm start`
3. เปิด `http://localhost:3000`
4. หากต้องการให้มือถือเครื่องอื่นเข้าใช้งาน ให้เปิดผ่าน IP ของเครื่องที่รันเซิร์ฟเวอร์ในวงแลนเดียวกัน
5. ครั้งแรกที่เปิดระบบจะให้ตั้งรหัสผ่านก่อนเข้าใช้งาน

## โครงสร้างไฟล์

- `server.js` เซิร์ฟเวอร์กลางและการอัปเดตแบบเรียลไทม์
- `public/auth.html` หน้าเข้าสู่ระบบและตั้งรหัสผ่าน
- `public/app.html` หน้าแอปหลัก
- `public/styles.css` งานออกแบบหน้าจอ
- `public/app.js` ตรรกะการแชร์พิกัดและแผนที่
- `public/auth.js` ตรรกะการตั้งรหัสผ่านและล็อกอิน
- `data/auth.json` เก็บรหัสผ่านแบบเข้ารหัสแฮชหลังตั้งค่าครั้งแรก
- `capacitor.config.ts` ตั้งค่า Android shell และ URL ของ production server
- `mobile-shell/index.html` หน้า fallback สำหรับ Android shell ก่อนผูกเซิร์ฟเวอร์จริง
- `android/` โปรเจกต์ Android สำหรับเปิดใน Android Studio และสร้างไฟล์ AAB

## หมายเหตุสำหรับการต่อยอด

- เวอร์ชันนี้เก็บข้อมูลในหน่วยความจำ เหมาะกับการทำต้นแบบและทดลองใช้งาน
- ถ้าจะใช้จริงควรเพิ่มระบบล็อกอิน, ฐานข้อมูล, ประวัติการเดินทาง, การแจ้งเตือน, และสิทธิ์การเข้าถึง
- ถ้าจะใช้จริงผ่านมือถือภายนอกวงแลน ควรเปิดผ่าน HTTPS เพื่อให้การติดตั้งและการแชร์พิกัดทำงานได้เสถียร

## เส้นทางขึ้น Play Store

1. นำเซิร์ฟเวอร์และหน้าเว็บขึ้นโดเมน HTTPS จริง
2. ตั้งค่า environment variable `CAP_SERVER_URL` ให้ชี้ไป URL ของระบบจริง เช่น `https://family.example.com/app`
3. รัน `npm run android:sync`
4. เปิดโปรเจกต์ด้วย `npm run android:open`
5. ใช้ Android Studio สร้าง signed Android App Bundle (`.aab`) เพื่ออัปขึ้น Play Console

## ข้อควรรู้สำหรับ Google Play

- แอปใหม่บน Google Play ต้องส่งเป็น Android App Bundle (`.aab`)
- ถ้าเป็นบัญชี Play Console แบบบุคคลที่สร้างใหม่หลังวันที่ 13 พฤศจิกายน 2023 จะมีข้อกำหนดเรื่องการทดสอบก่อนเปิดใช้งานจริง

## เส้นทางขึ้นเซิร์ฟเวอร์จริง

โปรเจกต์นี้มีไฟล์ `render.yaml` สำหรับใช้กับ Render แล้ว ซึ่งเหมาะกับแอปแบบ Node.js + Express + Socket.IO และได้ HTTPS ทันทีหลัง deploy

1. นำโค้ดชุดนี้ขึ้น GitHub
2. สร้าง Web Service ใหม่บน Render แล้วเลือก repository นี้
3. ให้ Render อ่านค่าจาก `render.yaml`
4. ตั้ง environment variables อย่างน้อย:
   - `SESSION_SECRET` เป็นค่าสุ่มยาวสำหรับ session
   - `AUTH_PASSWORD` เป็นรหัสผ่านแรกของระบบ production
5. รอ deploy สำเร็จ แล้วเปิด URL ที่ Render ให้ เช่น `https://family-tracker.onrender.com`

หมายเหตุสำคัญ:

- ถ้าตั้ง `AUTH_PASSWORD` หรือ `AUTH_PASSWORD_HASH` ระบบจะใช้รหัสผ่านจาก environment ของเซิร์ฟเวอร์แทนไฟล์ในเครื่อง
- production จะใช้ secure cookie อัตโนมัติ
- มี endpoint ตรวจสุขภาพที่ `/health`
- ข้อมูลตำแหน่งสมาชิกยังเก็บในหน่วยความจำ จึงเหมาะกับ MVP; ถ้าจะใช้จริงระยะยาวควรเพิ่มฐานข้อมูลและ session store
