Android Shell Ready

แอป Android ถูกตั้งโครงไว้แล้ว

ตอนนี้ตัวแอป Play Store ยังต้องชี้ไปหาเซิร์ฟเวอร์จริงแบบ HTTPS ก่อน จึงจะเปิดระบบติดตามครอบครัวได้ครบ

ขั้นต่อไปก่อน build ขึ้น Play Store:

  1. นำเว็บและเซิร์ฟเวอร์ขึ้นโฮสต์จริง เช่น https://family.example.com
  2. ตั้งค่า CAP_SERVER_URL ให้ชี้ไป URL ของระบบจริง
  3. สั่ง sync Android project ใหม่ แล้วเปิดใน Android Studio เพื่อสร้างไฟล์ AAB
